# Taha — Frontend Developer Portfolio

A modern, light/dark portfolio for Taha Mahmoud, built with Next.js 16, React 19, TypeScript, and Tailwind CSS v4.

## Features

- **Light/dark theme** — toggle in the nav, persists to `localStorage`, respects system preference by default
- **Interactive 3D hero** — Three.js gallery tunnel whose colors follow the active theme
- **Modern dev-portfolio design** — acid-green accent, glassy nav, rounded surfaces, mono micro-labels
- **Animated stats** — counters that count up on scroll (disabled with `prefers-reduced-motion`)
- **Accessible** — semantic HTML, labeled form fields, visible focus rings, keyboard-navigable nav

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Scripts

| Script      | Purpose                      |
| ----------- | ---------------------------- |
| `npm run dev` | Start the development server |
| `npm run build` | Production build           |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint                 |
